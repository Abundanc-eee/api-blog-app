This is a blog post app that was created using Next.js, Tailwind and a JSONPlaceholder API 


I created this Next.js project with "create-next-app" which is the official way to create a next project. 

You can run the code in the terminal by typing "npm run dev"
Open the "https://localhost3000" link in your broswer to see the outcome of your code

For the app, the posts and comments under the posts are from the JSONPlaceholder API i used to fetch data 
A post can be created, edited or deleted 
The API also allows for fake persistence that is, when a user creates, edits or deletes a post, it does not reflect in the API but it hows in the Network tab when you go to DevTools in your browser
